# BUG 修复报告

## 基本信息
- 日期：2026-09-20
- 模块/功能：笔记入口与响应式布局
- 严重级别：中
- 影响范围：已登录用户在窄屏设备上创建和编辑笔记

## 问题描述
- 期望结果：用户在任意已登录页面都能找到新建笔记入口，页面在窄屏下不会横向溢出。
- 实际结果：新建入口只在笔记列表页右上角；顶栏和编辑页未充分处理窄屏收缩与换行。

## 复现步骤
1) 使用宽度不超过 640px 的浏览器窗口打开应用并登录。
2) 查看顶栏和笔记编辑页面。
3) 观察新建入口是否显眼，以及页面是否可横向滚动或控件被挤出。

## 定位过程
- 新建笔记路由和后端创建接口已经存在，但入口没有在全局顶栏提供。
- 顶栏、笔记页头部和编辑页头部缺少换行及可收缩约束；标题输入框未显式允许收缩。

## 修复方案
- 顶栏新增始终可见的“新建笔记”入口，指向既有 `/notes/new` 路由。
- 为顶栏、列表页头部、分页栏和编辑页头部增加窄屏换行规则。
- 为标题输入框增加 `min-width: 0`，限制用户名显示宽度，并禁止页面横向溢出。

## 变更内容
- `frontend/src/components/layout/AppLayout.vue`
- `frontend/src/views/NoteListView.vue`
- `frontend/src/views/NoteEditView.vue`
- `frontend/src/styles/theme.css`

## 手动验证步骤
1) 打开 `http://localhost:8088/` 并登录。
2) 在顶栏点击“新建笔记”，确认进入编辑页。
3) 输入 Markdown 标题、列表或代码块，点击保存，确认可创建笔记。
4) 将浏览器宽度缩小到 640px 以下，确认顶栏、按钮、编辑器和预览区均换行显示且页面没有横向滚动条。
